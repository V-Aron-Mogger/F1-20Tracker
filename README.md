# F1-20Tracker
You need to start to download this in powershell "pip install matplotlib numpy"
#In F1 2020 Settings → Telemetry Settings → UDP Telemetry: On, UDP IP Address: 127.0.0.1, UDP Port: 20777, UDP Format: 2020, Broadcast Mode: Off.
Start the python file in powershell
Open Cmd type "ipconfig" search for IPv4: (192.128.x.x)
In a browser type Http://{your ip adress}:8000
then you just go around the track and it will load and you can see the map and the other drivers too
If you are going on a new track restart the python file
